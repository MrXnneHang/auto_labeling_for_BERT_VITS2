## ADL

这个功能之后会完全集成在 [XnneHangLab](https://github.com/XnneHangLab/XnneHangLab) 中.

它使用 funasr 生成字幕并且根据每句话的起止点把音频中的空白片段去除, 以 2s 空白音频填充, 防止有的录屏视频中总时长 30 分钟但是讲话的时长实际上不到 5 分钟, 那会在后续的降噪和音频预处理中浪费大量算力和时间.
